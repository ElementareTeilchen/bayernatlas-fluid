# Changelog

## Unreleased

- Custom point icons rendered as image symbols in one native KML layer.
- Icons that the BayernAtlas proxy cannot fetch fall back to standard markers.
- `showLabels` controls icon labels; icon points stay selectable without labels.

## 0.1.0 - 2026-09-03

- Initial public release of the maps2-independent `baf:map` Fluid component.
- Plain-array points, lines, polygons, circles, categories and local details.
- Optional base-map/category controls and item-selection events for adapters.
- Initial viewport and server-rendered dimensions to avoid post-load repositioning.
- TYPO3 13.4/14.3 PHP and JavaScript tests, usage examples and deployment checklist.
- Fluid 4.3+ and 5.3.1+ support, including the dependency required by TYPO3 14.3.

The upstream web component remains in beta. See `Documentation/Deployment.md`
for domain approval, consent ownership and outstanding browser acceptance.
